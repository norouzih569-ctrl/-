# مدیریت آرایشگاه – نسخه اندروید

نسخه‌ی اندروید (جاوا) برنامه‌ی مدیریت آرایشگاه که قبلاً برای ویندوز با پایتون نوشته شده بود.

## امکانات
- **نوبت‌ها**: انتخاب روز (تقویم شمسی)، افزودن/ویرایش/حذف نوبت، جلوگیری از رزرو ساعت تکراری، جستجوی نام مشتری، درآمد روز، اعلان نیم‌ساعت قبل از نوبت
- **مشتریان**: افزودن، ویرایش، حذف، تماس مستقیم
- **هزینه‌ها**: ثبت و حذف هزینه با تاریخ شمسی
- **آرایشگران درصدی**: ثبت آرایشگر و سرویس‌ها با محاسبه‌ی سهم سالن و آرایشگر
- **گزارش ماهانه**: درآمد، سهم سالن، هزینه‌ها و مانده
- **تنظیم قیمت خدمات**، **پشتیبان‌گیری و بازیابی** (فایل `salon.db` نسخه ویندوز را هم می‌شود مستقیم بازیابی کرد)

## گرفتن فایل APK از GitHub
1. یک مخزن (Repository) جدید در GitHub بسازید.
2. همه‌ی فایل‌های این پوشه را (شامل پوشه‌ی مخفی `.github`) در ریشه‌ی مخزن آپلود کنید.
3. به تب **Actions** بروید؛ workflow با نام «Build Android APK» خودکار اجرا می‌شود
   (یا از خود همین تب دکمه‌ی *Run workflow* را بزنید).
4. بعد از تمام شدن (حدود ۳ تا ۶ دقیقه) وارد اجرای موفق شوید و از بخش **Artifacts** فایل `BarberApp-apk` را دانلود کنید.
5. فایل `BarberApp.apk` را به گوشی منتقل و نصب کنید (اجازه‌ی «نصب از منبع ناشناس» لازم است).

برای گرفتن APK به‌صورت **Release**، یک تگ مثل `v1.0` بسازید؛ فایل APK خودکار به صفحه‌ی Releases اضافه می‌شود.

## تنظیمات مهم (فایل `AppConfig.java`)
- `BUILD_EXPIRY`: تاریخ انقضای نسخه (مثل نسخه ویندوز). برای غیرفعال کردن، مقدار را `""` بگذارید.
- `SUPPORT_PHONE`, `CURRENCY`: شماره پشتیبانی و واحد پول.

## انتقال اطلاعات از نسخه‌ی ویندوز
فایل `salon.db` را به گوشی بفرستید (تلگرام/درایو/USB)، سپس در برنامه:
منوی بالا (⋮) ← «بازیابی از فایل پشتیبان» ← انتخاب `salon.db`.
